# Netflix Data Visualization Project

This project focuses on transforming raw Netflix Movies and TV Shows data into meaningful visualizations using Python libraries like Pandas, Matplotlib, and Seaborn.

The project helps in understanding trends, content distribution, ratings, and release patterns through different charts and graphs.

---

## Tools & Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* VS Code

---

## Dataset Used

* Netflix Movies and TV Shows Dataset (`netflix_titles.csv`)

---

## Visualizations Created

### 1. Movies vs TV Shows

A count plot showing the distribution of Movies and TV Shows available on Netflix.

### 2. Top 10 Countries

A bar chart representing the top 10 countries contributing the most Netflix content.

### 3. Content Ratings Distribution

A visualization showing the frequency of different content ratings on Netflix.

### 4. Release Year Trend

A line graph displaying release year trends of Netflix content.

---

## Key Insights

* Netflix contains more Movies than TV Shows.
* Some countries contribute significantly more content than others.
* TV-MA is one of the most common content ratings.
* Content releases increased rapidly in recent years.
